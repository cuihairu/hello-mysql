# 工具与实战

这里记下我在项目和排障中用过的 MySQL 工具，以及它们在数据库设计、维护和优化中的实际用法。

## [MySQL工具](mysql-tools.md)

- **[MySQL Workbench](mysql-workbench.md)**  
  MySQL Workbench 提供可视化数据库设计、查询编写和数据迁移等功能；我把常用操作和适用场景记在这里。

- **[phpMyAdmin](phpmyadmin.md)**  
  phpMyAdmin 是基于 Web 的 MySQL 管理工具，适合快速处理常见的数据库管理操作。

- **[MySQL Shell](mysql-shell.md)**  
  MySQL Shell 支持 SQL、JavaScript 和 Python，并提供 CLI；这里记录我用它做自动化任务和复杂查询的方式。

- **[Percona Toolkit](percona-toolkit.md)**  
  Percona Toolkit 是一组用于数据库管理和性能优化的命令行工具，我主要用它们做性能分析和问题排查。

## [实际案例](real-world-cases.md)

下面这些案例记录了我如何把 MySQL 工具用在具体业务场景的设计和优化中。

- **[电商系统数据库设计与优化](e-commerce-system.md)**  
  探讨电商系统的数据库设计方案，包括如何处理订单、用户数据以及产品信息等，同时提供优化策略来提升性能。

- **[社交网络数据库设计与优化](social-network-system.md)**  
  研究社交网络平台的数据库设计，包括用户关系、帖子内容和互动等数据的管理，分析如何优化以支持大规模用户访问。

- **[日志处理与分析系统](log-processing-analysis.md)**  
  介绍如何设计和优化一个日志处理与分析系统，处理高吞吐量的日志数据，并进行有效的查询和分析。

这些工具和案例来自实际使用记录，涉及数据库设计、优化和问题排查。
