# Tools and Practice

The MySQL tools I have used across projects and troubleshooting, and how they actually played out in database design, maintenance and optimisation.

## [MySQL Tools](mysql-tools.md)

- **[MySQL Workbench](mysql-workbench.md)**  
  MySQL Workbench provides visual database design, query editing and data migration; I keep my frequently used operations and where they fit here.

- **[phpMyAdmin](phpmyadmin.md)**  
  phpMyAdmin is a web-based MySQL administration tool, handy for quick day-to-day database management.

- **[MySQL Shell](mysql-shell.md)**  
  MySQL Shell speaks SQL, JavaScript and Python and has a CLI; this page records how I use it for automation and complex queries.

- **[Percona Toolkit](percona-toolkit.md)**  
  Percona Toolkit is a set of command-line tools for database administration and performance work; I mainly use it for performance analysis and troubleshooting.
